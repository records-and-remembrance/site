# コピー・文言レビューシート

現行モックのコピーを、**記録を調べる人が内容をすぐ理解できる**方向に書き直しました。このシートはその初稿です。各行を「採用 / 修正 / 保留」で確認し、修正する場合は人が完成文を記入してください。記入内容を次のモック修正に反映します。

文体の基準は、短く具体的に書くこと、比喩より記録の種類と調べられる内容を伝えること、確認できた情報と未登録の情報を区別することです。
