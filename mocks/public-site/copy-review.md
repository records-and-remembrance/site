# キャッチコピー・文言レビューシート

静的モックに入っている主要なコピーを、役割ごとに並べました。**現状案はどれも仮置き**です。人が「採用 / 修正 / 保留」を選び、書き換える場合は修正文を記入してください。記入後、その内容をモックに反映します。

文言の見直しでは、まず #1〜#4 のサイトの核を決め、その後で発見カードと各画面の説明を合わせると、言葉のトーンが揃いやすくなります。

## 先に返す修正

すべてを一度に書かなくて構いません。まず核となる項目を3つ選び、完成形の文を記入してください。

1. 項目番号：［　］ 採用 / 修正：［　］ 完成文：［記入］
2. 項目番号：［　］ 採用 / 修正：［　］ 完成文：［記入］
