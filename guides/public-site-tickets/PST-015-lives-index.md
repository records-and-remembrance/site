# PST-015 ライブ一覧

- フェーズ: P2
- 対応箇所: 設計書 §3.2、§4.7
- 想定サイズ: マイグレーション1本相当
- 依存: PST-008

## 目的

395件のeventを年と基本メタデータから探し、ライブ詳細へ進める一覧を作る。

## 実装範囲

- `/lives` の年セレクタ、年別件数、日付、event名、会場、演奏曲数。
- event type、未来eventの予定表示、セットリスト0件の表現。
- event slugからライブ詳細へのリンク。
- project／venueフィルタを受け取るデータ境界（URL復帰はPST-018）。

## テスト方針

- 年別集計、event名NULL、venue名、演奏0件、未来eventをfixtureで先にテストする。
- eventDate順と同日データの決定的な並び順を検証する。
- 予定eventを過去eventと同じセットリスト前提で扱わないことを確認する。
- 年セレクタと一覧を静的ページ上で操作し、URL契約をPST-018へ接続する。

## 受け入れ条件

- 年別件数付きセレクタから対象年のevent一覧を表示できる。
- 日付、event名、会場、演奏曲数からライブ詳細へ遷移できる。
- 未来eventに予定バッジを表示し、セットリスト空でも正常に描画する。
- startTimeやticketPriceがNULLのとき空欄行を作らない。
- projectとvenueの選択値を共有フィルタ基盤へ渡せる。

## 対象外

ライブ詳細の前後ナビ、セットリストのvariationNote、会場詳細の定番曲。
