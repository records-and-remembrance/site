# PST-023 人物相関図

- フェーズ: P4
- 対応箇所: 設計書 §4.8
- 想定サイズ: マイグレーション1本相当
- 依存: PST-003、PST-010

## 目的

人物と門田関連プロジェクトのmembershipを、回遊可能なグラフとして表示する。

## 実装範囲

- `/network` のperson×project二部グラフ。
- project 8ノードのカラー、2プロジェクト以上の人物強調、1プロジェクト人物の初期ミュート。
- supportを含む／除くトグル、ホバー／タップ時のエッジ強調。
- 人物クリックから`/people/:slug`、projectクリックから`/projects/:slug`への遷移。
- グラフと同内容のモバイル向けリスト。
- listとSVGは同じ最小 `NetworkModel` から生成する。静的リストを先に出し、重いforce-layout
  実装はnetworkが表示対象になってから読み込む。グラフのためにサイト全体へD3を含めない。

## テスト方針

- ノード・エッジ生成をfixtureで先にテストし、support除外と複数project数を検証する。
- クリック、キーボード操作、トグル、タップでの選択状態をブラウザテストする。
- ノード順や座標ではなく、関係性・リンク先・状態変化をテストする。
- ノード数120程度と空データで、描画失敗や操作不能がないことを確認する。
- JS無効時も、同じ人物・projectのリンクを持つリストで回遊できることを確認する。

## 受け入れ条件

- membershipから人物・projectのノードとエッジが生成される。
- support除外時にsupport membershipのエッジが消え、再表示で戻る。
- 2プロジェクト以上の人物が視覚的に区別される。
- マウスが使えない環境でも、リストまたはキーボードで同じ詳細へ進める。
- 初期版は`scope = 'monden'`を中心に表示し、外部scopeを誤って門田名義として扱わない。

## 対象外

外部プロジェクトの調査・入力と、depth 2以降の段階展開（PST-024）。
