# PST-004 ジャケット画像のR2・admin登録

- フェーズ: P0
- 対応箇所: 設計書 §2、§4.5、§10-2
- 想定サイズ: マイグレーション1本相当
- 依存: PST-001

## 目的

release単位のジャケット画像をCloudflare R2へ保存し、URLと実画像サイズをadminからDBへ登録できるようにする。

## 実装範囲

- R2 object key、許可する画像形式・サイズ、失敗時のエラー契約。
- アップロード結果から `artworkUrl` / `artworkWidth` / `artworkHeight` を保存するadmin API。
- release編集画面からのアップロード、既存画像の表示、差し替え。
- 公開側が使うURLとwidth/heightの値を欠損なく返す。

## テスト方針

- R2をモックしたAPIテストを先に書き、成功・形式不正・容量超過・保存失敗を検証する。
- 画像の縦長・横長・正方形をfixtureで扱い、DBに実寸が保存されることを確認する。
- adminの状態テストでアップロード中、成功、失敗、差し替えを検証する。
- DBではrelease以外の行を変更しないことと、URLだけ／サイズだけの不完全保存を拒否する契約を確認する。

## 受け入れ条件

- adminからreleaseを選び、R2へ画像を保存して3つの値を同一操作でDBに登録できる。
- 横長画像を正方形に切り抜かず、元の縦横比を公開側へ渡せる。
- 不正形式・上限超過・R2失敗はDBを更新せず、利用者へ復旧可能なエラーを表示する。
- 既存画像を差し替えてもreleaseの他のメタデータは保持される。
- 認証や公開範囲など既存adminの境界を越える公開APIを追加しない。

## 対象外

公開サイトの画像コンポーネントの見た目、全作品への画像投入作業。
