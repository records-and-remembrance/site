# PST-009 プロジェクト一覧・詳細

- フェーズ: P2
- 対応箇所: 設計書 §3.2、§4.3
- 想定サイズ: マイグレーション1本相当
- 依存: PST-008

## 目的

現在の門田関連プロジェクトを活動期間と関連データから辿れる最初の回遊起点にする。件数を
画面実装にハードコードしない。

## 実装範囲

- `/projects` の一覧、活動期間、type、件数、scopeの初期表示。初期一覧と集計は
  `scope = 'monden'` に限定し、externalはPST-024まで混ぜない。
- `/projects/:slug` のヘッダ、description、活動期間。
- membershipのGantt、役割・楽器、supportの視覚表現。
- work一覧（primary / participantを明記）、年別ライブ本数、会場上位5、よく演奏された曲Top 10。
  同数時は表示名、slugの順で並べて順位を決定する。
- 人物、作品、ライブ、楽曲へのリンク。

## テスト方針

- 先に一覧・詳細のデータ契約とリンク先をfixtureでテストする。
- membershipの開始日だけ、終了日なし、support、役割なしを検証する。
- 関連データが0件でもページが成立し、集計が捏造されないことを確認する。
- 主要なプロジェクト詳細を静的buildし、404・リンク切れがないことを検証する。

## 受け入れ条件

- `/projects` から各確定slugの詳細へ遷移できる。
- Ganttでsupportが破線・薄色になり、人物名が人物詳細へリンクされる。
- work、ライブ、会場、Top 10の各ブロックが仕様順に表示される。
- 活動期間がNULLの関連データを勝手に補完せず、表示可能な範囲で描画する。
- 詳細画面に人物・作品・ライブ・楽曲のうち存在する隣接リンクが2系統以上ある。
- PST-024でexternalデータを追加しても、初期一覧・件数・Top集計にexternalが混入しない。

## 対象外

年表、networkのグラフ、プロジェクトフィルタのURL状態管理。
