# PST-013 楽曲一覧

- フェーズ: P2
- 対応箇所: 設計書 §3.2、§4.6
- 想定サイズ: マイグレーション1本相当
- 依存: PST-008

## 目的

演奏回数を入口に、楽曲の収録・録音・ライブの線へ進める一覧を作る。

## 実装範囲

- `/songs` のタイトル、作曲・作詞者、録音数、収録作品数、演奏回数、初出年。
- 初期ソートを演奏回数順とし、ソート対象を明示する。
- 初出年を初出releaseのreleaseDateで導出する。
- 録音0件の楽曲を「ライブ演奏のみ」として表示する。
- 楽曲slugへのリンク。

## テスト方針

- track・recording・event_performanceの集計を小さなfixtureで先に検証する。
- recording 0件、releaseDate NULL、creditなし、同数ソートの挙動をテストする。
- 「演奏回数順」が初期状態であることを画面契約として確認する。
- 行の表示とhrefを検証し、テーブルのDOM配置そのものは固定しない。

## 受け入れ条件

- `/songs` から確定slugの楽曲詳細へ遷移できる。
- 演奏回数、録音数、収録作品数が同じ集計定義で表示される。
- recording 0件の曲が欠損扱いにならず、ライブ演奏のみと表示される。
- recordingYearがNULLでも、利用可能な初出releaseDateを年として表示する。
- 初期一覧が演奏回数の多い順に並ぶ。

## 対象外

曲の旅、年別ヒートストリップ、3年以上の演奏間隔検出。
