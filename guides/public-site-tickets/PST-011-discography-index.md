# PST-011 ディスコグラフィ一覧

- フェーズ: P2
- 対応箇所: 設計書 §3.2、§4.5
- 想定サイズ: マイグレーション1本相当
- 依存: PST-004、PST-008

## 目的

大判ジャケットを入口に、作品ページへ進めるディスコグラフィ一覧を作る。

## 実装範囲

- `/discography` の作品カード、代表版のジャケット、タイトル、年、format、catalog#。
- 正方形・長方形の実画像比率を保持した表示。
- 画像なし作品のタイポグラフィックfallback。
- work typeのグループ化、participant表示、作品slugへのリンク。
- フィルタUIを受け取れるデータモデル（状態復帰はPST-018）。

## テスト方針

- 画像あり／なし、横長、participant、track未登録のfixtureを先にテストする。
- 代表版の選択が同じ入力で安定することを検証する。
- カードの表示情報と詳細hrefを契約テストする。
- 1200px、640px、モバイル幅で画像比率とカードの崩れをスクリーンショット確認する。

## 受け入れ条件

- 作品カードをクリックすると `/discography/:slug` へ遷移する。
- artworkWidth/Heightを使い、画像を正方形に切り抜かない。
- artworkなし作品が欠損表示にならず、タイトル・年・format・catalog#を表示する。
- compilationのparticipantをprimaryと混同しない表示にする。
- フィルタ値を後続のPST-018へ渡せるデータ境界を持つ。

## 対象外

版ごとの差分、再発系譜、トラックリストの詳細、Pagefind検索。
